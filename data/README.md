For Phase II official sample acquisition, hashes, event splits and execution, see [the data and reproduction guide](../reports/phase2/REPRODUCIBILITY.md). The instructions below describe the original Phase I sector adapter.

TRACK-X generates synthetic events locally. For the public challenge simulation, sign in to Kaggle, visit the [TrackML competition](https://www.kaggle.com/competitions/trackml-particle-identification/data), review its rules and accept the terms if eligible. Select a training archive only after checking its listed size. Extract one matching eventNNNNNNNNN prefix with hits, truth, cells and particles into data/trackml/. Do not redistribute challenge files. No download command runs during installation or experiments.

After training the smoke models, run `uv run python -m trackx.trackml data/trackml/event000001000 --phi 0` with your actual event prefix. Input can be plain or gzipped CSV. Volume 8 even layers 2–8 are mapped to four radial indices, coordinates converted from mm to m. The default azimuthal sector has half-width 0.15 rad. Exceeding the hit or row cap raises an error. Counts and eligible particles refer only to the sector. The adapter streams cells and particles through rows() when requested. Reconstruction uses only hit positions and detector layer. Ground truth is joined by integer hit ID. See the [reference loader and table definitions](https://github.com/LAL/trackml-library/blob/master/trackml/dataset.py).

Phase I official-file evaluation: NOT RUN at that stage. Schema fixtures exercise the reader. Synthetic-trained scores on a supplied event are a transfer check; the public challenge uses a different weighted scoring rule.
