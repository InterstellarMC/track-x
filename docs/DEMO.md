# Demo narration (about 75 seconds)

**0–15 s.** Open the local inspector on the synthetic smoke split. Each dot is a measured position on one of eight cylindrical layers. Rotate the event and switch to truth to see which hits came from each simulated particle.

**15–35 s.** Switch between classical, MLP, GNN and hybrid reconstruction. Each method starts from the same candidate graph. Turn on missed and false candidate edges. A high edge score still has to compete for exclusive ownership of both hits.

**35–50 s.** Select one track and inspect its longitudinal residuals. The fit assumes a prompt helix in a uniform field. A small residual measures consistency with that model; it cannot establish particle identity.

**50–75 s.** Open the three-seed results. Nominal efficiency saturates for several methods. In combined stress, compare GNN and hybrid fake rates alongside efficiency. The same checkpoint produced both rows. End on the official-file evaluation status and the next barrel-sector validation step.
