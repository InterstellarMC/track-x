# Experiment protocol

A seed and event number initialize a separate NumPy generator. Splits are contiguous, disjoint event ranges within each seed. Hit order is shuffled. Standardization uses sums and squared sums over training nodes/edges only. An epoch visits every training event, with one graph per optimizer step. AdamW uses learning rate 0.002, global gradient norm limit 2 and per-event positive BCE weight clamp(negatives/positives, 0.25, 20). Save the lowest event-mean unweighted validation BCE and stop after four unimproved epochs. Test data never select weights or thresholds.

## Denominators

- Candidate edges are positive when both hits have the same nonzero particle ID. Precision = TP / predicted positives, recall = TP / candidate positives, F1 = 2TP / (predicted positives + candidate positives), all at score ≥0.5. AP is the stepwise precision–recall integral over distinct scores. Candidate-only recall excludes true links lost during graph construction. The classically computed edge score is a ranking heuristic.
- Require three observed hits for an eligible truth particle and three hits for an output track. For intersection size m, purity is m / candidate length and completeness is m / all observed hits of this particle. Require purity >0.5 and completeness ≥0.5. This asymmetric rule makes the majority unique, while allowing an exactly half-complete fragment. Process paths in ascending start-node order. The first qualifying path claims the truth particle. Subsequent qualifiers count as duplicates. Unmatched paths count as fakes.
- Efficiency is unique matched particles / eligible particles. Fake and duplicate rates each divide by all output tracks. Purity and completeness average over first matches only. Track-level efficiency can be high despite missing hits. pT MAE uses finite fitted momenta on these matches. z RMS pools longitudinal hit residuals from all output paths. Neither statistic is a calibrated pull.
- Every JSON row represents one method on one event. Undefined metrics are null. Tables average defined event values per seed, then weight three seeds equally. The ± is sample SD across three seed means, not a confidence interval. Timing warms each event-method once, then times score transfer to host, assembly and fitting. Preprocessing times a separate uncached graph build. Throughput is the inverse of their sum. Excludes simulation, matching and visualization. Device microbenchmarks synchronize MPS.
- RSS is the process lifetime high-water mark at evaluation, including earlier work in the same process. Serialized event data are generated on demand. test_array_bytes measures the test split's raw hit and integer truth buffers, excluding metadata. Cache budget defaults to 32 MiB with oldest-file eviction. Run one writer at a time.

## Samples

The mac_m1 split has 60 training, 10 validation and 15 test events per seed. Nominal events have 32 particles and 80 noise hits, with 10% missing hits. The combined stress condition changes to 54 tracks, 220 noise hits, 24% losses, a 45 mm vertex spread and pT floor 0.15 GeV/c. The separate pileup proxy assigns 54 tracks to five shared longitudinal vertices. It models geometric overlap only. Both shifts reuse nominal weights. The same seed/event tuple across conditions provides reproducible scenarios, not identical underlying particles. The stress design does not isolate individual causes of degradation.
