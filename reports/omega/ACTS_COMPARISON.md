# ACTS comparison and upstream scope

**Matched reconstruction NOT RUN.** TRACK-X consumes official simulated global coordinates, three detector-volume identifiers and a table of module transforms. A valid ACTS comparison needs a tracking geometry with matching surfaces, a mapping of TrackML modules to ACTS source links and local measurement axes, a common field/material hypothesis, matched event selection, and an adapter from trajectory states to full-event hit IDs. An ACTS executable was absent from the checked environment. Running a different detector’s example would leave those differences unresolved. The obstacle is input equivalence; ARM64 compatibility alone would not resolve it. [ACTS project](https://github.com/acts-project/acts) · [ACTS tracking](https://acts.readthedocs.io/en/stable/tracking.html)

A bounded upstream opportunity concerns reproducibility of detector-specific seed settings. Open issue 1699 asks for default seeding parameters for ODD and later ITk. A useful contribution would document the exact example, geometry, release, resolved configuration and a deterministic seed-count check, using an ACTS-native example. TRACK-X provides evidence of sensitivity to seed selection and a tested event-level provenance pattern. Its tuned tolerances should not be ported to ODD. Review the current example and existing documentation with a maintainer before authoring an upstream patch. ACTS asks contributors to describe the problem in an issue before implementing substantial changes. No ACTS-native defect or numerical improvement was reproduced here. Patch and external contact remain pending. [Open issue 1699](https://github.com/acts-project/acts/issues/1699) · [Contribution guidelines](https://github.com/acts-project/acts/blob/main/CONTRIBUTING.md)

A matched benchmark would first pin an ACTS revision, generate a single straight/curved crossing fixture on the matched surfaces, verify global↔local and hit-ID round trips, translate uncertainties and run a single TrackML event. Check the reference score on known assignments, then freeze both full pipelines, seeding region, thread count, warmup and timing boundaries before selecting independent events. An alternative is to run both algorithms on common ODD simulation and label the resulting metric as an ODD study.
