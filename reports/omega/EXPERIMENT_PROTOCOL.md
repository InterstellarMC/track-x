# Prospective Omega protocol

Source baseline a67e798, Phase IV two-pass geometry seeds and local M3. Primary endpoint is the organizers' full-event weighted score on complete simulated events. Compare methods on identical events, complete submissions, single CPU process and geometry. Secondary endpoints use Phase IV definitions for full-event efficiency, fake, duplicate, purity, coverage, mixed and severe merge rates. Separately measure seed contamination and exact retention of baseline all-one-signal seeds.

Development 1003–1005, selection 1002, training unnecessary. Historical events through 1026 are excluded from confirmation. Evaluate frozen geometry, local and global EKF, strict residual rejection, bounded alternate pixel hypotheses, whole-path ambiguity with alternate seeds, and the existing tighter EKF gate. Select among novel seed methods by highest validation score subject to score ≥ baseline, mixed ≤ baseline and efficiency ≥ baseline−0.002. If none qualify, retain baseline and test highest-scoring novel seed method as a challenger. No adjustment after confirmation.

After committing code and selection, inspect only the central directory of official train_1.zip. From sorted complete IDs above 1026 select twelve evenly spaced positions from first to last inclusive. If range reads or members unavailable, apply the identical deterministic rule to train_sample.zip. Never substitute individual events based on outcomes. Use all twelve or report incomplete data. Record archive name and hashes. Distinct archives from the same simulation are not distinct detector conditions.

Budget ≤12 fresh events, ≤3 batches of four, ≤80 MB network/batch plus central-directory checks, ≤600 MB additional raw storage, ≥3 GiB free, single event in memory, CPU-first, ≤5 GB process RSS target. At most four historical development/validation events and one confirmation comparison; no hyperparameter sweep. Abort on input or split mismatch. Resume at validated event boundaries. Freeze selection before any confirmation payload. Equal-event paired means and 10,000 paired percentile bootstrap draws with seed 1729. Report individual results, SD and intervals. Promote only if mean score improves, mean mixed fraction falls and efficiency loss is ≤0.002 absolute; report runtime separately. No extrapolation to measured LHC collisions. Stop once hypotheses and confirmation are evaluated.
